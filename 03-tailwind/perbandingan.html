Tombol yang sama, dua cara

1. CSS Biasa

Style ditulis terpisah di <style> / file .css

<button class="tombol-css">
      .tombol-css {
        padding: 12px 24px;
        border-radius: 8px;
        background: #0ea5e9;
        color: white;
        font-weight: bold;
      }
      .tombol-css:hover {
        background: #0284c7;
      }
